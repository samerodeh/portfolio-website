# Portfolio Website

Samer Odeh’s buildless personal website, published at https://samerodeh-dev.vercel.app/.

## Structure

- `dist/` contains the complete website source and public assets.
- `vercel.json` serves `dist/` without a framework or build step.

## Development

Run `python3 -m http.server 4173 --directory dist` to preview. Preserve the blue/slate themes, circular portrait, responsive navigation, fox animation, and page transitions. Check affected pages on desktop and mobile before publishing. Use factual project descriptions and genuine screenshots. Keep the user-provided resume PDF unchanged unless a replacement is supplied.

## Version control and deployment

Use `main` as the production branch. Push only when the user authorizes it. Do not use worktrees or add AI attribution or co-author trailers. Keep credentials and `.vercel/` outside Git. Changes in featured project repositories require separate authorization.
